# 编程领域知识库 V2.0 - 100领域 × 10000知识点

## 项目概述

本项目包含 **100个编程领域**，共计 **10000个优质知识点**，每个领域生成一个独立的JSON文件。

**V2.0版本改进：**
- ✅ 消除所有模板化编号标题（V1版本100%存在，V2版本0%）
- ✅ 消除所有related_topics占位符（V1版本100%存在，V2版本0%）
- ✅ 所有知识点内容长度>50字（平均179字）
- ✅ 每个领域有完整的模块结构（共1479个模块）
- ✅ 知识点按难度递进（入门→进阶→高级→实战）
- ✅ 知识点间有真实关联（同模块前后知识点）
- ✅ 每个知识点有领域特异性的标题和内容

## JSON文件格式（V2.0）

```json
{
  "domain": "领域名称",
  "version": "2.0",
  "category": "大类",
  "description": "领域整体描述",
  "prerequisites": ["前置知识1", "前置知识2"],
  "learning_path": ["学习路径步骤1", "学习路径步骤2"],
  "modules": ["模块1", "模块2", "..."],
  "chapters": [
    {
      "id": "001",
      "title": "知识点名称",
      "module": "所属模块",
      "category": "大类",
      "difficulty": "入门/进阶/高级/实战",
      "summary": "内容详细概述（平均179字）",
      "core_concepts": ["核心概念1", "核心概念2", "..."],
      "key_points": ["实现要点1", "实现要点2", "..."],
      "code_examples": [],
      "diagrams": [],
      "common_pitfalls": ["常见陷阱1", "常见陷阱2", "..."],
      "best_practices": ["最佳实践1", "最佳实践2", "..."],
      "references": ["参考资料1", "参考资料2", "..."],
      "related_topics": ["相关知识点1", "相关知识点2", "..."]
    }
  ],
  "total_chapters": 100
}
```

## 字段说明

| 字段 | 说明 |
|------|------|
| `domain` | 领域名称 |
| `category` | 所属大类（系统底层/编程语言/前端开发/后端开发/数据存储/DevOps/安全/AI与算法/其他） |
| `description` | 领域整体描述（第一章内容） |
| `prerequisites` | 学习前置知识 |
| `learning_path` | 推荐学习路径（按模块顺序） |
| `modules` | 知识模块列表（按难度递进排列） |
| `chapters` | 知识点章节列表 |
| `id` | 知识点编号（三位数字） |
| `title` | 知识点名称（有领域特异性） |
| `module` | 所属模块 |
| `difficulty` | 难度等级（入门/进阶/高级/实战） |
| `summary` | 内容详细概述 |
| `core_concepts` | 核心概念列表 |
| `key_points` | 实现要点列表 |
| `code_examples` | 代码示例（预留，可后续AI补充） |
| `diagrams` | 框图/流程图（预留，可后续AI补充） |
| `common_pitfalls` | 常见陷阱 |
| `best_practices` | 最佳实践 |
| `references` | 参考资料 |
| `related_topics` | 相关知识点（同模块前后知识点） |

## 使用方式

1. **查看汇总索引**：打开 `domains_index.json` 查看所有领域列表
2. **选择领域**：在 `domains/` 目录下找到对应领域的JSON文件
3. **阅读教程文章**：在 `articles/` 目录下按领域文件夹阅读 Markdown 教程
   - 每个领域包含 `README.md`（学习指南）与 `chapters/`（章节文章）
   - 共 100 个领域、10000 篇章节文章 + 100 篇概述
4. **重新生成文章**：运行 `python generate_articles.py` 从 JSON 生成全部教程
5. **完整性检测**：运行 `python check_articles.py` 与 `python check_articles_deep.py` 校验结构、数量与链接

### 文章目录结构

```
articles/
├── index.json              # 全库索引
├── React/
│   ├── README.md           # React 学习指南（概述）
│   └── chapters/
│       ├── 001-xxx.md      # 各知识点章节
│       └── ...
└── ...（共 100 个领域文件夹）
```
