# Web性能优化 学习指南

> **分类**：前端开发 ｜ **技术生态**：Lighthouse、WebPageTest、HTTP/2/3、RUM、Sentry


## 领域定位

Web 性能影响用户体验与业务指标。Core Web Vitals 驱动加载、渲染、网络与运行时系统化优化。

以指标驱动：度量、资源加载、缓存 CDN、代码分割到性能预算与 Lighthouse。

本领域常用技术栈与工具包括：Lighthouse、WebPageTest、HTTP/2/3、RUM、Sentry。

## 学习目标

- 测量解读 LCP/INP/CLS
- 制定加载渲染网络方案
- 多级缓存与 CDN
- 性能监控与预算

## 前置知识

- 浏览器原理
- HTTP 缓存
- 构建工具
