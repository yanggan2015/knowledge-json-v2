### 核心知识

**1. 注入原理**

用户输入拼接到 SQL 语句，改变查询语义。经典：' OR 1=1 --

**2. 参数化查询**

使用 PreparedStatement/ORM 参数绑定，输入与 SQL 结构分离。

**3. 最小权限**

数据库账户仅授予必要表/操作权限，即使注入也限制破坏范围。
