### 核心知识

**1. CORS 机制**

浏览器通过 Origin 头 + Access-Control-Allow-Origin 控制跨域访问。

**2. 错误配置**

Access-Control-Allow-Origin: * 配合 credentials 允许任意站点读取。

**3. 安全实践**

白名单 Origin，不使用通配符；敏感 API 禁止跨域。
