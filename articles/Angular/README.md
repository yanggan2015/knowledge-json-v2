# Angular 学习指南

> **分类**：前端开发 ｜ **技术生态**：Angular 17+、RxJS、NgRx、Angular Material、CLI


## 领域定位

Angular 是企业级 TypeScript 框架，依赖注入、RxJS 与完整 CLI 工具链适合大型长期维护项目。

组件、模板、DI、路由、表单、HTTP、RxJS、NgRx 与 OnPush 性能优化。

本领域常用技术栈与工具包括：Angular 17+、RxJS、NgRx、Angular Material、CLI。

## 学习目标

- Angular CLI 项目管理
- DI 与变更检测
- 路由表单 HTTP
- 测试与 OnPush 优化

## 前置知识

- TypeScript
- OOP 与模块化
- HTML/CSS
