# 实时系统 学习指南

> **分类**：系统底层 ｜ **技术生态**：FreeRTOS, Zephyr, PREEMPT_RT, Xenomai, RTEMS, WCET 分析工具


## 领域定位

实时系统保证任务在截止时间内完成，分为硬实时（错过即失效）与软实时（可容忍偶尔超时）。调度算法、优先级继承、确定性 I/O 与 RTOS/RT-Linux 是核心主题。

面向工业控制、汽车电子与通信设备工程师，强调可调度性分析与最坏情况响应时间。

本领域常用技术栈与工具包括：FreeRTOS, Zephyr, PREEMPT_RT, Xenomai, RTEMS, WCET 分析工具。

## 学习目标

- 区分硬实时/软实时/尽力而为并选择合适调度策略
- 使用 RMS/EDF 进行可调度性分析
- 配置 PREEMPT_RT 补丁与 CPU 隔离降低抖动
- 设计容错与看门狗机制保障安全关键系统

## 前置知识

- 操作系统原理
- C 语言
- 嵌入式基础
- 概率与调度理论入门
