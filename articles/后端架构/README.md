# 后端架构 学习指南

> **分类**：后端开发 ｜ **技术生态**：Spring Cloud、Istio、Kafka、Redis、PostgreSQL、Prometheus


## 领域定位

后端架构定义系统的边界、分层与演进路径，从单体到微服务、从同步 REST 到事件驱动，需要在一致性、可用性与团队组织之间权衡。

本领域覆盖架构风格（分层、CQRS、DDD）、横切能力（缓存、消息、高可用）与 API/数据架构设计，面向 Tech Lead 与资深工程师。

本领域常用技术栈与工具包括：Spring Cloud、Istio、Kafka、Redis、PostgreSQL、Prometheus。

## 学习目标

- 能评估单体与微服务拆分边界
- 能设计高可用与高并发架构方案
- 能绘制 C4/序列图沟通架构决策
- 能识别架构坏味道并制定演进路线

## 前置知识

- 至少一种后端语言
- HTTP 与数据库基础
- 分布式系统入门概念
