## 核心概念

Docker 将应用与依赖打包为镜像，基于 Linux Namespace 与 Cgroups 实现隔离，Docker Compose 与 Kubernetes 构成现代交付链路的基础层。

在 **Docker** 体系中，**Docker基础** 与上下游模块形成协作。技术栈以 **Docker 24+** 为核心（Shell/YAML），生态包括 Dockerfile, docker compose。

「Docker基础」是该领域的核心知识模块，理解其原理与边界是工程实践的基础。
