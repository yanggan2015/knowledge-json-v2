# Nginx 学习指南

> **分类**：DevOps ｜ **技术生态**：OpenResty、Lua、Certbot、nginx-prometheus-exporter


## 领域定位

Nginx 高性能事件驱动 Web 服务器，常用于反向代理、负载均衡、静态资源与 TLS 终结。

覆盖 master-worker 架构、location 匹配、upstream 与缓存限流。

本领域常用技术栈与工具包括：OpenResty、Lua、Certbot、nginx-prometheus-exporter。

## 学习目标

- 能配置虚拟主机与反向代理
- 能设置 SSL 与 HTTP/2
- 能调优 worker 与缓存
- 能分析 access/error log
