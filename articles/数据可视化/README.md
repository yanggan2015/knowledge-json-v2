# 数据可视化 学习指南

> **分类**：前端开发 ｜ **技术生态**：D3.js、ECharts、AntV、Three.js、Mapbox


## 领域定位

数据可视化将数据映射为图形。D3、ECharts、AntV、Three.js 覆盖 2D/3D、地图与大屏场景。

图表选型、主流库、Canvas/SVG/WebGL 差异、交互设计与性能优化。

本领域常用技术栈与工具包括：D3.js、ECharts、AntV、Three.js、Mapbox。

## 学习目标

- 选型图表与渲染技术
- ECharts/D3 交互图表
- Canvas/SVG/WebGL 性能
- 大屏项目实践

## 前置知识

- JavaScript
- CSS
- 数据分析基础
