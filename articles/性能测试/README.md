# 性能测试 学习指南

> **分类**：后端开发 ｜ **技术生态**：JMeter、Locust、Gatling、k6、Prometheus、perf


## 领域定位

性能测试验证系统在负载下的响应时间、吞吐与资源占用。负载测试、压力测试与 soak 测试对应不同目标与风险发现。

覆盖 JMeter、Locust、Gatling 与指标分析，连接 APM 定位瓶颈。

本领域常用技术栈与工具包括：JMeter、Locust、Gatling、k6、Prometheus、perf。

## 学习目标

- 能设计场景与并发模型
- 能解读 P95/P99 与吞吐曲线
- 能定位 CPU/IO/锁瓶颈
- 能输出性能测试报告

## 前置知识

- HTTP API
- 基本统计学（百分位）
- Linux 资源概念
