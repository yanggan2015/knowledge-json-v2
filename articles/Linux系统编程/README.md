# Linux系统编程 学习指南

> **分类**：系统底层 ｜ **技术生态**：glibc/musl, pthread, epoll/kqueue, strace, ltrace, valgrind, systemd


## 领域定位

Linux 系统编程在 POSIX 语义之上使用系统调用实现进程、文件、信号、线程与 IPC。掌握 open/read/write、fork/exec、pthread、epoll 等 API 是编写高性能服务端与工具链的必备技能。

面向 C/C++/Rust 系统程序员，侧重 man page 与内核行为的一致性理解及生产级错误处理。

本领域常用技术栈与工具包括：glibc/musl, pthread, epoll/kqueue, strace, ltrace, valgrind, systemd。

## 学习目标

- 熟练使用文件 I/O、进程控制、信号与多种 IPC 机制
- 能编写多线程程序并处理竞态、死锁与 EINTR 重试
- 掌握 epoll 边缘/水平触发与 Reactor 网络模型
- 能编写守护进程、处理僵尸进程并正确使用内存映射

## 前置知识

- C 语言
- Linux 命令行
- 基本网络概念
- Makefile/编译链接基础
