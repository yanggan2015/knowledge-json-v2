# 云计算 学习指南

> **分类**：DevOps ｜ **技术生态**：AWS、阿里云、Azure、Terraform、Kubernetes


## 领域定位

云计算按 IaaS/PaaS/SaaS 分层交付资源。公有云、私有云与混合云并存，云原生（容器+K8s+微服务）是主流架构范式。

覆盖 VPC、对象存储、托管 K8s、IAM 与 FinOps 成本优化。

本领域常用技术栈与工具包括：AWS、阿里云、Azure、Terraform、Kubernetes。

## 学习目标

- 能设计 VPC 与安全组
- 能使用托管数据库与对象存储
- 能评估多云与厂商锁定
- 能实施成本标签与预算告警

## 前置知识

- 网络基础
- Docker/K8s 入门
