# 计算机网络 学习指南

> **分类**：系统底层 ｜ **技术生态**：Wireshark, tcpdump, iperf3, curl, RFC 791/793/2616/8446, Linux iproute2


## 领域定位

计算机网络按 OSI/TCP-IP 分层讲解物理传输、路由交换、传输可靠性与应用协议。从以太网帧到 HTTP/3，理解各层首部字段、状态机与拥塞控制是网络编程与排障的核心。

面向网络工程师与后端开发者，结合 Wireshark 抓包与 socket 编程实践。

本领域常用技术栈与工具包括：Wireshark, tcpdump, iperf3, curl, RFC 791/793/2616/8446, Linux iproute2。

## 学习目标

- 手工解析 Ethernet/IP/TCP 首部并理解校验与分片
- 掌握 TCP 三次握手、滑动窗口、拥塞控制与 TIME_WAIT
- 能使用 socket API 编写客户端/服务端并处理非阻塞 I/O
- 理解 DNS、HTTP、TLS 及常见网络安全机制

## 前置知识

- 二进制与十六进制
- 基本编程能力
- 操作系统基础
- 概率统计基础
