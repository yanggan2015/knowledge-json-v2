## 核心概念

认证验证「你是谁」，授权决定「你能做什么」，Session、JWT、OAuth2 是 Web 与 API 安全的核心模式。

在 **认证授权** 体系中，**JWT** 与上下游模块形成协作。技术栈以 **认证授权** 为核心（通用），生态包括 行业标准工具链。

JWT 由 Header、Payload、Signature 三段 Base64URL 组成。服务端用密钥验证签名，Payload 可含 exp、sub 等声明。JWT 无状态但无法主动失效，需配合短过期与刷新令牌策略。
