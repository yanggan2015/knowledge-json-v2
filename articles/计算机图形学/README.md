# 计算机图形学 学习指南

> **分类**：其他 ｜ **技术生态**：OpenGL, Vulkan, DirectX, Three.js, Blender


## 领域定位

计算机图形学研究生成与渲染视觉图像的算法与系统。从光栅化管线、着色器到光线追踪与全局光照，OpenGL/Vulkan 是底层图形 API 标准。

面向图形程序员，从线性代数到现代渲染管线。

本领域常用技术栈与工具包括：OpenGL, Vulkan, DirectX, Three.js, Blender。

## 学习目标

- 理解 MVP 变换与渲染管线各阶段
- 编写 GLSL/HLSL 着色器
- 实现 Phong/Blinn 光照与纹理映射
- 了解光线追踪与全局光照原理

## 前置知识

- 线性代数
- C/C++
- 微积分
- 基本物理光学
