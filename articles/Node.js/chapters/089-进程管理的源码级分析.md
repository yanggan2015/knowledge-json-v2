## 核心概念

Node.js 基于 V8 与 libuv，单线程事件循环处理 I/O，适合高并发 I/O 密集型 API 与实时应用。

在 **Node.js** 体系中，**进程管理** 与上下游模块形成协作。技术栈以 **Node.js 20+** 为核心（JavaScript/TypeScript），生态包括 Express, Koa, Fastify。

操作系统通过 PCB 管理进程状态，调度器决定 CPU 分配策略。
