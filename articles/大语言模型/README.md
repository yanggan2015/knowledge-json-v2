# 大语言模型 学习指南

> **分类**：AI与算法 ｜ **章节总数**：150 ｜ **技术栈**：PyTorch/HF


## 领域概述

大语言模型是AI与算法领域的重要技术方向，本系列从基础到高级逐步深入，涵盖20个核心模块：LLM概述、Transformer架构、注意力机制、预训练、微调等。每个知识点作为独立章节，包含原理讲解、实现要点、常见陷阱和最佳实践，配合源码分析和架构图，帮助读者建立完整的大语言模型知识体系。

本教程基于 **Python** 与 **PyTorch/HF** 生态编写，涵盖 Transformers, LangChain 等主流工具与框架。每章独立成篇，文字精炼、逻辑清晰，适合系统学习与按需查阅。


## 你将学到什么

完成本系列后，你将能够：

- 系统理解 **大语言模型** 的核心概念与模块划分。
- 按难度递进掌握从入门到实战的完整知识路径。
- 在工程实践中做出合理的技术判断与问题排查。
- 通过章节索引快速定位所需知识点。
