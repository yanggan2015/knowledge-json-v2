# MongoDB 学习指南

> **分类**：数据存储 ｜ **技术生态**：mongosh、Compass、Atlas、Change Streams


## 领域定位

MongoDB 文档模型以 BSON 存储嵌套结构，复制集提供高可用，分片水平扩展。适合 schema 灵活、读写模式文档化的场景。

从 CRUD、聚合管道、索引到事务与分片，明确与关系库的选型边界。

本领域常用技术栈与工具包括：mongosh、Compass、Atlas、Change Streams。

## 学习目标

- 能设计文档模型与引用/嵌入
- 能配置复制集选举
- 能使用 aggregation pipeline
- 能规划分片键

## 前置知识

- JSON
- 分布式基础
