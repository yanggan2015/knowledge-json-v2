# 微服务架构 学习指南

> **分类**：后端开发 ｜ **技术生态**：Spring Cloud Alibaba、Consul、Istio、Jaeger、Nacos


## 领域定位

微服务将应用拆为可独立部署的服务单元，通过轻量通信（HTTP/gRPC/消息）协作，带来团队自治与技术异构，也引入分布式事务、观测与治理复杂度。

覆盖服务拆分、服务发现、网关、熔断限流、Saga 事务、链路追踪与服务网格，强调可运维性。

本领域常用技术栈与工具包括：Spring Cloud Alibaba、Consul、Istio、Jaeger、Nacos。

## 学习目标

- 能制定服务边界与数据所有权
- 能搭建服务发现与配置中心
- 能设计熔断降级与灰度发布
- 能建立分布式追踪与 SLO

## 前置知识

- 后端开发经验
- Docker 基础
- 网络与数据库
