# Git版本控制 学习指南

> **分类**：DevOps ｜ **技术生态**：GitHub、GitLab、Gitea、git-lfs


## 领域定位

Git 是分布式版本控制系统，快照 + 有向无环图记录历史。分支轻量，merge/rebase 是协作核心，工作流影响发布节奏。

从对象模型、分支合并到 GitFlow/GitHub Flow 与 bisect 排错。

本领域常用技术栈与工具包括：GitHub、GitLab、Gitea、git-lfs。

## 学习目标

- 理解 commit/tree/blob 对象
- 能安全 rebase 与解决冲突
- 能使用 bisect 定位回归
- 能制定团队分支策略
